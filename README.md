# ModbusRTUComm

> [!IMPORTANT]
> The `ogm/compat` line is an OpenGameMaster compatibility seed rooted at the
> exact CMB27 revision originally imported by OGM. It intentionally contains no
> replayed OGM transport changes yet. See [OGM_FORK_PROVENANCE.md](OGM_FORK_PROVENANCE.md)

This library provides some core functions for implementing Modbus RTU communication.
It is not a full implementation of Modbus RTU. Other libraries are available for that purpose.
